Most AI incident assistants forget everything the moment an outage ends. That's backwards for
on-call work, where the slowest step is remembering how the last similar failure was fixed.

I built EpistemicOps: an SRE incident-response agent whose whole point is memory, using Hindsight.

Cold incident → the agent investigates and writes a postmortem.
Hindsight retains + consolidates it into a runbook.
Warm incident → a related outage recalls that prior knowledge before investigating (memory_used=true).
Baseline mode turns memory off, so the difference is visible side by side.

Memory isn't a feature here — it's the product.
