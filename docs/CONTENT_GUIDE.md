# Hindsight Hackathon — Content Submission Guide (requirements as supplied)

> Source: the official Content Submission Guide requirements as supplied to this project by the
> participant in the final completion pass. Captured here so the submission docs can be verified
> against concrete rules. If an authoritative copy of the guide differs, that copy takes precedence.

## Article
- 800–1,500 words, English, public and linkable after publication.
- Title focused on the idea/result.
- **Must NOT mention "hackathon" anywhere in the article, and no hackathon references in hashtags.**
- First-person engineering voice; concrete technical story.
- Hindsight is a major theme.
- At least one real code snippet from the repository.
- A concrete before/after example.
- An honest lesson, limitation, or dead end.
- Screenshots/images and an architecture diagram.
- Links: Hindsight GitHub, Hindsight documentation, Vectorize agent-memory.
- Publish on a public developer platform: Medium, Dev.to, Hashnode, Substack, or LinkedIn Articles
  (not a Google-Drive-only file).

## Reddit
- Share the article as a **Link post** on one of: r/llmdevs, r/sideproject, r/aiagents, r/aimemory.

## Social post
- English; **must NOT mention "hackathon"; no #Hackathon; no student-focused tags.**
- Strong first two lines; project-focused; concrete Hindsight behavior; before/after.
- Positively mention Hindsight agent memory.
- Under 800 characters; hashtags on the final line only.
- Project GitHub link in the MAIN post.
- First comment links to the Hindsight GitHub repository.
- Suggested hashtags (use only relevant): #AIAgents #AI #Hindsight #AgentMemory #AIMemory #LLM.
- Tag Code.in on LinkedIn and Articles.

## Video
- One team video, 2–5 minutes, 1080p minimum, screen recording with voiceover (talking head optional).
- Structure: intro ~30s · problem ~30s · live demo ~2–3 min · wrap-up ~30s.
- Must show: agent without memory, real interaction, Hindsight retain, Hindsight recall,
  before/after moment, one key takeaway.
- Public YouTube upload with a 16:9 thumbnail (not Google-Drive-only).

## Per-team-member content
- Each team member submits their own article and social post.

## LLM
- Any LLM permitted; Groq listed as a free-tier option.
